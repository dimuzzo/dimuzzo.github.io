# Alessandro Demo (dimuzzo) - Portfolio Website

A minimalist, mobile-first portfolio website showcasing my work in AI, data analytics, and software engineering. Built with vanilla HTML, CSS, and JavaScript - no frameworks, just clean code.

## 🎨 Design Philosophy

Inspired by The Weeknd's aesthetic with a dark, moody theme featuring:
- Pure black background (#000)
- Red accent color (#ff0000) for interactions
- Clean typography using Inter font
- Minimal, distraction-free layout

## 🚀 Features

- **Responsive Design** - Optimized for mobile and desktop viewing
- **Fixed Navigation** - Smooth scrolling navigation bar with logo
- **Project Showcase** - Highlighted projects with live demos and source links
- **Skills Matrix** - Organized technical skills by category
- **Contact Links** - Direct links to GitHub, LinkedIn, and Telegram

## 📁 Project Structure

```
portfolio/
├── index.html          # Main HTML structure
├── style.css           # All styling and responsive design
├── script.js           # Smooth scroll functionality
└── assets/
    └── mylogo.png      # Logo image for navigation
```

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts (Inter)

## 📱 Mobile Optimization

The website is fully responsive with specific optimizations for mobile devices:
- Touch-friendly navigation
- Optimized font sizes for smaller screens
- Flexible layouts that adapt to screen width
- Reduced spacing for better mobile UX

## 🎯 Featured Projects

### Spatial Benchmark
Comparative performance analysis of geospatial database engines using DuckDB, PostGIS, and GeoPandas.

### Quiz App Engine
Interactive quiz application built with vanilla JavaScript demonstrating DOM manipulation and state management.

### NBA Predictor
Machine learning model for predicting NBA game outcomes using Python and TensorFlow.
